# ADR-0020：控制塔壳 v1（4 tab + 任务详情 + 内联对话）

- 状态：**代码完成、文档收口；真机最终布局确认待补**（2026-11-12）
- 日期：2026-11-12
- 关联：`docs/task-control-shell.md`、`docs/frontend-ia.md`、ADR-0013（交付物检阅）、
  ADR-0018（任务生命周期）、`packages/web/src/app/Shell.tsx`

## 背景

手机端原来是“聊天首页”：首屏就是对话，审批、产出、设备、规则都挂在同一页。
任务一多，第一眼不知道现在有没有事、谁在跑、产出在哪；控制塔的“可信/看得见”不成立。

壳卡的目标不是加功能，而是换信息架构：

- 4 个一级 tab：总览 / 智能体 / 交付物 / 控制；**聊天不再是一级 tab**
- 当前会话的聊天/审批/产出进任务详情
- 总览只回答“现在有没有事”
- 不重做审批、产出、权限、设备逻辑；不改 host 协议

## 决定

### 1. 4 tab + hash 路由

- `#/overview`、`#/agents`、`#/artifacts`、`#/control`、`#/task/<id>`
- 默认 `overview`；未知 hash 回落 `overview`
- 与旧 token/session hash 兼容：不认识的 hash 不当错误，只回落
- 没有“聊天”tab；聊天在任务详情/内联对话里

### 2. 总览是“状态摘要”，不是第二套聊天

- 顶部：电脑、在线、设备、待批
- 待你决定：真实审批 + 待验收交付物
- 智能体矩阵：真实 Executor；Planner/Reviewer/拉取 **P2 灰显**
- 运行中：真实当前会话
- 电脑：入口/设备；没有 CPU/内存就写“未接”，不画假仪表盘
- 最近交付物：真实本轮/最近产出
- 命令条：对 Agent 说…

**没有数据就空态**，不拿示意数据填。

### 3. 内联对话，而不是弹 modal / 切路由

用户反馈：发指令不应该切界面；控制卡片折起来，回复要在同一页可见。

最终：

- 在总览点命令条 → 总览卡片折叠，当前页出现 Timeline + Composer
- 路由仍是 `#/overview`，不跳任务详情
- “收起对话”恢复总览
- 任务详情仍保留完整聊天、审批、产出

这解决了“弹层挡住回复”和“切页丢上下文”两个问题；代价是总览多了一个 chat 状态。

### 4. 任务详情复用旧组件

- 聊天、审批卡、计划卡、产出、停止全部复用
- 非当前会话只读；顶部明确“只读”
- 返回后 tab 状态保持

### 5. 交付物直开

- 列表项点击直接进 `ArtifactPreview`
- 不再强制先进“交付物仓库”再点一次
- 仓库仍可从抽屉进；全仓库筛选留到下一卡

### 6. 主题

- `html[data-theme="light|dark"]`；默认跟随系统，手动选择存 localStorage
- 白天：暖白底、白卡、控制蓝主操作
- 夜晚：中性石墨黑（`#0f1217`），**不是深绿**
- 绿色只表示完成/在线；琥珀只表示待批；P2 灰显

### 7. 账号/设置

- 这是我的抽屉里的“本地模式”；账号、团队、订阅 P2
- 不假登录、不放假头像
- 忘记设备清本地凭据回配对页

### 8. 不动 host 协议

- 复用现有 WS / store / 审批 / 产出 / 设备 / 权限
- 壳只改 UI 和路由
- 没有为了壳新增 host API

## 后果

**得到：**

- 首屏不再被聊天占满；总览回答“有没有事”
- 聊天仍可达，且是同页内联，不丢上下文
- 审批/产出/权限逻辑没有分叉
- 主题和交付物直开是低风险增量

**欠账/代价：**

- 内联对话让总览多一个状态，后续要和“审美减负”一起收
- 总览仍有信息密度问题；已另出减负方案，暂搁置
- 真机最终布局未确认；`QuickComposer` 已删但死 CSS 已清
- 未做 1+2+3 任务收件箱/详情分段；未做真实多 Agent/账号/中继

## 不做

- 不把聊天放回一级 tab
- 不做桌面侧边栏
- 不做真实多 Agent 拉取/编排
- 不接 CPU/GPU/进程指标
- 不做账号/团队/订阅
- 不做交付物全仓库筛选（下一卡）
