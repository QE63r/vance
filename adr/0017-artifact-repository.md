# ADR-0017：交付物仓库（索引、验收状态、历史取件）

- 状态：已接受并落地 v1（2026-11-09）
- 日期：2026-11-09
- 关联：ADR-0013（交付物检阅）、`docs/frontend-ia.md` v2、（内部交接文档已移除） §6

## 背景

现在只有“每个会话最近一次产出”（`latestArtifacts`）。手机上的“本轮产出”一刷新就只剩
最后一轮；历史文件虽然还在桌面上，但没有列表、没有验收状态、没有按会话/时间筛选。
控制塔的“交付物”页如果建在这上面，就是空壳。

## 决定

1. **在广播产出时建索引**，不靠事后扫盘：
   - `broadcastArtifacts` 时对 `added` / `changed` 的文件读一次，记
     `path / session_id / turn_id / sha256 / size / content_type / at / status=pending`
   - 为什么是广播时：历史里只有路径；事后文件可能已经变了，验收必须绑“当时看到的字节”。
   - 同一 `session + path + sha256` 只记一条，避免每轮重复。

2. **索引落盘**：`~/.vance/artifacts.json`（host-demo 传；测试传临时目录）。
   不配路径时只在内存里，测试不碰用户目录。最多保留 5000 条。

3. **`GET /artifacts`**：token 保护，按 `session_id` / `status` / `limit` 查；
   返回 `exists` / `changed`（文件被删或大小变了）。**不读全文、不做摘要、不转格式。**

4. **验收状态跟着记录走**：`/artifacts/accept` 重新算 sha；一致才把对应记录改成
   `accepted` / `rejected`，写 `note` / `decided_at`，并落盘。文件变了仍 409。

5. **历史文件可取件**：`/artifacts/ticket` 原来只认本轮产出；现在也认仓库记录，
   这样仓库里点旧文件能看原件。票据仍 60 秒、单文件、绑定 sha。

6. **前端先做“交付物仓库”面板**：菜单入口；筛选全部/待验收/已收/已打回；
   点一条看原件；确认/打回仍走现有 `/artifacts/accept`。不依赖控制塔壳。

## 后果

- 交付物页有真数据，不再只看本轮；重启后状态还在。
- 文件被删/改会标出来；点开会 404 或验收 409，不会假装还能收。
- 索引只记录“广播时存在且可读”的文件；Agent 产出后立刻被删的不会留下空记录。
- 还没有：全仓库搜索、按类型筛、docx/xlsx 预览、批量验收；这些后续做。

## 没做什么

- 没有把文件内容存进索引；只存元数据 + sha。
- 没有自动重扫历史流水补索引；上线前的旧产出不会自动出现在仓库里。
- 没有做跨电脑/多用户仓库；仍是单机单用户。
