# 梵境 · 项目构想与计划书

> 版本：2026-11-07（P0 收尾）
> 这份文档回答三件事：**做什么、为什么这么做、接下来做什么**。
> 具体取舍看 `adr/`；每张任务卡看 `docs/task-*.md`。

---

## 0. 一句话

**手机是电脑上 Agent 的操作端：看得见、说得上、停得下、做得了。**

卖的不是效率，是"人不用守在屏幕前"。

## 1. 问题

Agent 已经能在电脑上干活：改文件、跑命令、生成文档。但人必须坐在屏幕前：

- 它要删东西、改配置，你得在终端里点同意；
- 它卡住了、跑偏了，你得回去按 Ctrl+C；
- 它做完了，你得回到工位才知道结果行不行。

梵境把这三件事搬到手机上：**看见它在干什么、拦住它要干的事、验收它干完的活、随时叫停或接下一句。**

## 2. 是什么，不是什么

**是控制面**：传输、审批、会话、审计、呈现。

**不是**：

- 不是 Agent 运行时——不替它思考、不替它调模型；
- 不是 Agent 调试器——不认识某个 Agent 的命令方言；
- 不是 AI 摘要器——只搬运原件与事实，不生成解释；
- 不是远程桌面——默认只接管"审批"这一种交互。

判断优先级（有分歧时按这个）：

```
可信 > 好用 > 跨生态
看得见 > 能操作 > 全自动
```

## 3. 用户与场景

1. **离开工位的人**：手机上看进度、批一条命令、按停止。
2. **要验收交付物的人**：活干完了，打开产出的文件读一遍，确认交付或打回重做。
3. **不放心全自动的人**：每一步都能看见证据，关键动作必须自己点头。

## 4. 三条不能破的底线

| 底线 | 含义 |
|---|---|
| **fail-closed** | 拿不准就拒绝/问人；不静默放行，也不静默挂着 |
| **批准绑定原始字节** | 你批的是什么，执行的就是什么；转述不算数 |
| **风险按事实算** | 命令文本只用于展示；风险由适配器给出的 facts 计算 |

## 5. 架构：三层 + 两条腿

```
执行层  Agent（opencode / Claude Code / Codex …）+ 本地工具
          ↓ 适配器：原样字节 + 结构化事实（读/写/删除/程序/危险）
决策层  policy：只读事实 → 禁止 / 记住 / 只读放行 / 问人
          ↓
呈现层  host（传输、会话、审计、静态托管）+ 手机
```

- **协议腿**：Agent 愿意把"动手前的决定"交出来（ACP / Hook）→ 完整审批。
- **桌面腿**（未做）：Agent 不开放接口（Cursor/Copilot 等）→ 识别它的审批弹窗，
  手机上点允许/拒绝；只点识别到的弹窗，不做通用远程控制。

换 Agent 只加适配器：host / policy / web 不动。这是"跨生态"的全部含义。

## 6. 审批的完整闭环

审批不止"拦风险"，还有"验交付"：

| | 事前审批 | 事后验收 |
|---|---|---|
| 问题 | 这个动作能不能做 | 做出来的东西行不行 |
| 看什么 | 命令、路径、影响 | **交付物原件** |
| 谁判断 | 你点允许/拒绝 | 你读、看、听，决定收不收 |

验收这一层**不做 AI 摘要**：客户读的是文件本身，不是我们的转述。
验收绑定文件 sha256——你确认的就是你看到的字节。

取文件用**短时单文件票据**（60 秒、只对一个文件），主 token 只放请求头，不进链接。

## 7. 现状（2026-11-07）

已完成：

- 手机连电脑、扫码、设备配对；2 fps 实时画面；
- 真前端 `/app/`：会话视图 + `⋯` 菜单（任务列表/切换/规则撤销）；
- 会话身份：消息带 `session_id`，`/sessions`，旧账只读；
- 审计与产出：`decision` 进流水，`artifacts` 结构化，`GET /rules` + 撤销；
- **事实契约**：policy 不再读命令文本，命令方言在适配器；
- 流式片段合并，历史不再从中间截断；
- 测试 **114 项**全过；仓库在 GitHub（私有），tag 留了每个阶段的回滚点。

运行方式：opencode + DeepSeek（当前 `deepseek-v4-pro`，推理强但吃预算）；
Claude Code 因 API 403、Gemini 因网络问题暂不可用。

## 8. 路线图

### P0（已完成）

单机、单用户、opencode、审批、会话、产出、事实契约、任务列表。

### P1（当前）

1. **交付物检阅**（下一张卡）：产出原件可看、确认交付/打回，验收绑定 sha256。
2. **token hash**：门钥匙别出现在地址栏/日志；旧链接会失效，要动二维码/启动器/文档。
3. **完成提醒**：识别"完成/等待/卡住"三态，先只提醒 + 证据，不自动继续。

### P2

4. **桌面审批接管**：识别软件弹窗，手机点允许/拒绝（只点识别到的弹窗）。
5. **远程输入**：手机发一句话，打进当前窗口；这时才具备"继续下一步"。
6. **多设备 / 客户账号**：验收人可能不是操作人。
7. **加密与中继**：现在明文到 Funnel；relay 仍是空壳。

### 跨阶段

- 接入 Claude Code / Codex / Gemini：等账号或网络可用，按 `adapter-contract.md` 写适配器；
- 适配器一致性测试：同一份 facts 必须得到同一判定，防止策略再被方言污染。

## 9. 非目标

- 不做 Agent 运行时，不训练/托管模型；
- 不做 AI 摘要、不自动批准、不替用户做验收决定；
- 不做通用远程桌面；
- 不接"自己批自己、不开放审批"的云端 Agent——那只是另一个聊天框；
- 不为了多平台牺牲 Windows 上已经跑通的路径（先做好一台机器）。

## 10. 怎么算成功

三个场景能稳定完成，就算产品成立：

1. 出门在外，手机收到审批 → 看一眼 → 批准/拒绝 → 它继续干活；
2. 活干完，手机打开交付物原件读一遍 → 确认交付，或写一句意见打回；
3. 任何时候按停止，3 秒内真的停下；断网恢复后上下文还在。

## 11. 已知风险与未解问题

| 风险 | 现状 |
|---|---|
| Agent 生态依赖 | 只有 opencode 可用；Claude 403、Google 超时；换 CLI 要账号/网络/适配器 |
| 模型质量 | DeepSeek V4 Pro 推理强但吃预算，低预算会空回复；需真实任务判断 |
| 安全 | token 长期固定、在 query；无加密；无多用户权限模型 |
| 桌面腿 | UI 自动化碎片化；Electron 需无障碍；UAC 不可碰 |
| 通知 | 网页关闭/锁屏收不到；真推送要 PWA + 推送服务 |
| 单执行 | 一次只跑一个会话；多会话并发未做 |
