# 下一张任务卡：权限档位（profiles）

> 仓库：`C:\Users\1\Desktop\梵境\vance`；先 cd 过去。

【任务】把“每个动作都问”改成三档权限：只读 / 工作区 / 完全。
默认工作区；完全权限需在手机上显式切换，且只对当前任务有效；
硬禁止（系统目录、凭据、磁盘级操作）任何档位都不放。

【验收】

1. `pnpm test` 全过，新增 ≥5 条：
   只读档下 edit 要问；工作区档下桌面写文件放行；工作区档下写系统目录仍禁止；
   完全档下普通写放行但格式化仍禁止；`/profile` 读写与 hello 携带当前档位。
2. 真机：生成 docx 这类任务，工作区档审批 ≤1 次；
   切到只读档后，同样的任务会重新问；切回工作区后不再问。
3. 硬禁止不变：写 `C:\Windows`、`C:\Program Files`、动 `.ssh` 仍然被拦，任何档位都拦。

【边界】

- 档位只影响“要不要问”，不影响 DENY 清单
- 不做“AI 自己声明风险/自己提档”；档位只能人切
- 不做长期“完全权限”；任务结束/重启回到默认档
- 不改事件信封；档位是 host 的会话状态
- 不做计划级审批（另立卡）

【口径】

- 三档：
  - `read-only`：只读放行，其余全问；
  - `workspace`（默认）：工作区内的写/删/改、以及运行工作区内的脚本 → 放行；
    工作区外、或拿不到目标路径的执行 → 问；
  - `full`：除硬禁止外全部放行；仅当前任务有效，重启回默认。
- 工作区根目录（默认）：
  - `C:\Users\1\Desktop`
  - `C:\Users\1\Desktop\梵境\sandbox`
  - `%TEMP%\opencode`（Agent 写脚本的地方）
  可用 `VANCE_WORKSPACE` 追加。
- 位置：host 的 `/profile`（GET/POST），手机「⋯ → 权限档位」切换；
  hello 带 `profile`，切换时广播。
- 审计：档位变更进流水（谁、何时、从哪档到哪档）。
